# Alien Resurrection PSX - cestina

Cesky preklad hry **Alien Resurrection** pro PlayStation 1.

Tento repozitar obsahuje pouze `.xdelta` patch a navod.  
Neobsahuje zadne originalni soubory hry, ISO/BIN/CUE image, audio, grafiku ani jina data chranena autorskymi pravy.

Patch je urcen pouze pro vlastni legalni kopii hry:

**Alien Resurrection (Europe) (En,Fr,De,Es,It)**

## Preklad

- cestina bez diakritiky
- texty jsou v **English slotu**
- audio zustava anglicke
- ve hre zvolte jazyk **ENGLISH**

## Navod k aplikaci patche

1. Stahnete si **xdelta UI**:  
   https://www.romhacking.net/utilities/598/

2. Stahnete si `.xdelta` patch z tohoto repozitare.

3. V xdelta UI vyberte:
   - **Patch:** `.xdelta` soubor z tohoto repozitare
   - **Source file:** puvodni soubor  
     `Alien Resurrection (Europe) (En,Fr,De,Es,It) (Track 1).bin`
   - **Output file:** novy vystupni soubor s názvem  
     `Alien Resurrection (Europe) (En,Fr,De,Es,It) (Track 1).bin`

4. Vysledny `.bin` soubor pouzijte misto puvodniho Track 1 `.bin` souboru.

5. Spustte hru v emulatoru nebo na vlastnim zarizeni a ve vyberu jazyka zvolte **ENGLISH**.

## Kompatibilita

Patch je urcen pro konkretni evropskou verzi hry:

`Alien Resurrection (Europe) (En,Fr,De,Es,It)`

Jine regiony nebo jine revize hry nemusi fungovat.
